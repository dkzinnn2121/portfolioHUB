# Projetos Pessoais 💻

Esta pasta contém projetos desenvolvidos por iniciativa própria para fortalecer minha lógica de programação e domínio de linguagens de baixo nível.

### 🛠️ Projeto em Destaque: Conversor de Unidades Técnico
Um software desenvolvido em C++ focado em conversões de medidas e escalas térmicas para uso em engenharia.

- Funcionalidades:** Conversão entre Celsius, Fahrenheit e Kelvin; conversão de unidades de medida.
- Tecnologias: C++, Lógica de Programação, Manipulação de Variáveis.
- Como executar: Compile o arquivo `.cpp` utilizando um compilador como o GCC e execute o binário gerado.
